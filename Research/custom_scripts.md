Налаштування користувацької гри (Custom game settings):

  --world-size SIZE
      Кількість кімнат у світі.

  --nb-objects NB
      Мінімальна кількість об'єктів у світі.


Налаштування граматики (Grammar settings):

  --theme THEME
      Тема, яка використовується для генерування тексту.
      Значення за замовчуванням: house (будинок).

  --include-adj
      Увімкнути використання прикметників.

  --blend-descriptions
      Об'єднувати описи в послідовних реченнях.

  --ambiguous-instructions
      Посилатися на об'єкт за його типом
      (наприклад, "червоний контейнер" замість "червона скриня").

  --only-last-action
      В інструкції описувати лише останню дію квесту.

  --blend-instructions
      Об'єднувати інструкції для послідовних дій.

  --entity-numbering
      Додавати номер після назви сутності, якщо недостатньо
      варіантів назв для їх розрізнення
      (наприклад, "червоне яблуко 2").


Налаштування квесту (Quest settings):

  --nb-parallel-quests NB_PARALLEL_QUESTS
      Кількість паралельних квестів, які матиме гра.
      Значення за замовчуванням: 1.

  --quest-length LENGTH
      Кількість дій, необхідних для виконання квесту.
      Це скорочений запис для:
          --quest-min-length N
          --quest-max-length N
          --quest-max-depth N

  --quest-breadth BREADTH
      Кількість підквестів, які матиме квест.
      Це скорочений запис для:
          --quest-min-breadth N
          --quest-max-breadth N


Розширені налаштування квесту (Quest settings — advanced):

  --quest-min-length LENGTH
      Мінімальна кількість дій, необхідних для виконання квесту.
      Це налаштування ігнорується, якщо задано --quest-length.
      Значення за замовчуванням: 1.

  --quest-max-length LENGTH
      Максимальна кількість дій, необхідних для виконання квесту.
      Це налаштування ігнорується, якщо задано --quest-length.
      Значення за замовчуванням: 5.

  --quest-min-breadth BREADTH
      Мінімальна кількість підквестів, які може мати квест.
      Це налаштування ігнорується, якщо задано --quest-breadth.
      Значення за замовчуванням: 1.

  --quest-max-breadth BREADTH
      Максимальна кількість підквестів, які може мати квест.
      Це налаштування ігнорується, якщо задано --quest-breadth.
      Значення за замовчуванням: 5.

  --quest-min-depth DEPTH
      Мінімальна кількість дій, яку можуть мати підквести.
      Значення за замовчуванням: 1.

  --quest-max-depth DEPTH
      Максимальна кількість дій, яку можуть мати підквести.
      Це налаштування ігнорується, якщо задано --quest-length.
      Значення за замовчуванням: 5.


Загальні налаштування (General settings):

  --output PATH
      Шлях, за яким буде збережено згенеровану гру.
      Якщо вказано каталог, для назви файлу буде використано
      UUID гри.

  --seed SEED
      Початкове значення (seed) генератора випадкових чисел.

  --format {z8}
      Формат, у якому буде скомпільовано гру.
      Значення за замовчуванням: z8.

  --overview
      Відобразити огляд згенерованої гри.

  --save-overview
      Зберегти зображення огляду згенерованої гри у форматі PNG
      поруч із файлом гри.

  -f, --force
      Примусово перезаписати наявний файл.

  --silent
      Тихий режим роботи.

  -v, --verbose
      Детальний режим виведення інформації.
      
tw-make custom --world-size 1 --nb-objects 2 --seed 1234 --output tw_games/custom_1room.z8

tw-play tw_games/custom_1room.z8 --viewer
